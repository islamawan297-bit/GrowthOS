# GrowthOS AI — Demo Static Site

This is a responsive, premium-looking static demo for the GrowthOS AI landing site. It includes a dark glassmorphism theme, animated statistics, an assistant preview, interactive Chart.js dashboard previews, and a small Three.js floating orb.

To run locally:

1. Open `index.html` in a browser (no server required).
2. For best results use a modern browser (Chrome, Edge, Safari, Firefox).

Files added:
- `index.html` — main markup
- `css/styles.css` — core styles
- `js/main.js` — interactions, charts, and 3D orb

CDNs used: Chart.js, Three.js, Google Fonts.
